### What was wrong in the sheet

- The sub-to-sub column is consistent (the PDF and the xlsx match row-for-row) and grouped contiguously,
  but Main/Sub labels often sit 1-4 rows off the items they head - e.g. the `Electronics` label starts on
  the `Tissue Paper` row, `Wall Clock & Watches` on `Shoe Bags`; only 112 of 258 sub labels line up exactly.
- Some item groups have no Sub label at all (e.g. cameras, TVs and mobile accessories inside Electronics;
  guitars and drums inside Musical Instruments; pet food inside Pet Supplies). These got a descriptive
  sub-category name (listed below) instead of being merged into an unrelated neighbour.
- The PDF has 47 pages and 1,397 data rows, 1,392 of them with an item (the brief's "~1,592" was an estimate).

## Catalog-slug mapping (how the display taxonomy links into the store)

The taxonomy is display data; links go to the existing storefront category tree (`/category/...`, the
live WooCommerce slugs). Each node is matched **by name** (case, `&`/`and`, punctuation and simple
plurals ignored) within its main category - `buildCategoryTaxonomy()` in
`packages/shared-client/src/category-taxonomy.ts`. Unmatched nodes link to the nearest matched
ancestor's category page; a main category with no catalogue match links to `/search?q=<name>`.

## Swapping in a corrected taxonomy (no UI change)

1. Replace `packages/shared-client/data/category-taxonomy.csv` - UTF-8, header
   `main_category,sub_category,sub_to_sub_category`, **one row per sub-to-sub item** with the main and sub
   filled on every row (no merged cells). Quote names containing commas.
2. Run `pnpm build:category-taxonomy` - regenerates `packages/shared-client/src/category-taxonomy.data.ts`.
3. Main-category banners: add `apps/web/public/categories/explore/<slug>.webp` (landscape, 960x400) and the
   slug to `DESKTOP_IMAGES` in `category-taxonomy.ts`; a main without one shows the placeholder.
   `CategoryImageSet.mobile` is the slot for the later portrait (mobile) image.

Display order is computed, not taken from the file: main and sub-categories alphabetical, sub-to-sub in
file order.
